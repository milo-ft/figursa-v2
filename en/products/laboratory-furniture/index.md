# Laboratory furniture

We design furniture in 2D and 3D from your spaces and services (air, water, gas, power, steam, vacuum). Modules keep the same depth and height, so they can be relocated and extended without losing uniformity.

## Features

- Computer-aided design in 2D and 3D
- Modules fully reusable when the layout changes
- Connection to every service line
